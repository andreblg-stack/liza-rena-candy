# Déploiement rapide

## GitHub Pages
Pour GitHub Pages, le contenu du dossier `frontend/` doit être publié comme site statique.
Le backend ne peut pas être exécuté par GitHub Pages.

## Backend
Déployer `backend/` sur un hébergeur Node.js HTTPS compatible.

Configurer `FRONTEND_ORIGIN` avec l'URL GitHub Pages.

## Important
Le code livré est une base complète de projet et un squelette fonctionnel, mais les éléments `XXXXX`, le vrai compte PayPal, l'authentification administrateur de production, la base de données de production et le stockage privé doivent être configurés avant de vendre réellement.
